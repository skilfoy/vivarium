# Authorized lab use only

Vivarium is a sealed habitat for evaluating security tools against fictional organizations. It is not a target list, and it is not permission.

You may use it only on infrastructure you own or are explicitly authorized to operate, and only against the address plan in this repository. Northline Mutual, Northline Indemnity, Hearthline, Calder Grid, Brinewater, Mercy Ledger, Glassport, Kindling, and Sable Watch are invented. Every person, policy, and record is synthetic.

The safety ceiling is `read-flag` or, later, `flip-simulator-bit`. A run that needs more than that is out of scope for this project.

## Prohibited

- Pointing any harness at a network this project does not own
- A default route, or any path from the habitat to the public internet
- Ransomware, wipers, worms, rootkits, and real exfiltration
- Publishing exploit procedures, payloads, or proof-of-concept code in this repo
- Treating Sable Watch, the management plane, or the operator plane as a target
- Putting the closed-source CAI product, paid pentest products, LazyOwn, or jailbreak repositories on the operator image

The upstream ARTEX project was publicly linked in October 2026 to intrusions against real financial institutions. This cage exists so an evaluation does not depend on the operator being careful. If a harness will not accept the scope file, it does not run.
