# Contributing

Vivarium is an authorized lab. Read [LEGAL.md](LEGAL.md) first. A change that cannot live inside those rules does not land.

## Reviewers reject

- Payloads, proof-of-concept code, and exploit archives
- Step-by-step intrusion procedures, in issues, catalogs, docs, or forge files
- Cleartext seed secrets, flag values, vault keys, cloud access keys, and private keys
- A default route, or any path from the habitat to the public internet
- A workflow that runs `terraform apply`

Class names and synthetic company data may be public. The answer key may not.

## What a change should do

Unknown catalog fields fail the schema check. A chain ceiling is `read-flag` or `flip-simulator-bit`. The scope file is the harness contract. Apply stays off. The preferred substrate, when there is a deployment, is free-tier AWS, and that deployment is not this pull request.

`node compiler/test.mjs`, `node services/smoke/test.mjs`, and `node compiler/doctor.mjs` pass before review.
